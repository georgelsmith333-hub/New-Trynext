4. **Validation started**
   - The page changed to **“Preparing…”**.
   - At this stage, the frontend sends a request to:

   ```text
   POST /api/admin/smart-mockups/browser-payload
   ```

   That endpoint must prepare and return two PSD payloads:

   - A modified PSD containing the uploaded artwork
   - The untouched original PSD for the baseline comparison

5. **That API request failed**
   - The live UI displayed:

   > **The API is temporarily unavailable.**

   - Because the PSD pair was never returned, Photopea never received the files.
   - Therefore, neither export was generated.
